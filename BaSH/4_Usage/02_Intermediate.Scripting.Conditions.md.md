# Conditions
Fundamental to all programming languages, is the ability to test conditionals resulting in statements for desired results. It's common for `if` statements to be accompanied by tooling with pass or fail exit codes. 0 is typical for 'success' and 1 and any other number than 0, is considered a 'fail' state. I'm going to expand on conditions using a specific tool that runs conditional tests which you will find in the following paragraph.

## The `test` or `[` command
