 ## Required:
 - glibc >= 2.17
 - curl >= 7.29.0
 - zlib >= 1.2.3
 - expat >= 2.0.1
 - openssl >= 1.0.1

 ## Recommended:
 - perl >= 5.16 (enables git scripting hooks)
 - libiconv (enables wide character support)
 - gettext (enables message translations)

 ## Optional:
 - libsecret (credential storage)
 - ccache (compilation caching for custom builds)
