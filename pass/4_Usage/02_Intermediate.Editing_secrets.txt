Editing secrets in a password vault:

   No surprises here:

     user@host:~$ pass edit api/stripe

 This opens your '$EDITOR' on the decrypted file, and re-encrypts on save/exit.

 Bare in mind, that you can ultimately put what ever you want in an edited file.
 The main point to keep in mind, however, is that you must dedicate the first
 line to each file as the password, or the output you wish to retrieve.
