To recall a password using 'pass':

   This part is totally plain.

     user@host:~$ pass email/gmail

   This prints out the secret to stdout
   Since it prints, you can use it to set a variable

     user@host:~$ export STRIPE_KEY="$( pass api/stripe )"

   Can be useful practice when deployed in scripts that you tend to keep the
 source code available to the public.

     user@host:~$ ORG_SECRET_KEY="account:${ pass api/stripe )"
     user@host:~$ STRIPE_API_VERSION='4.20'
     user@host:~$ cat script.sh
     #! /bin/bash --


     ORG_SECRET_KEY=${ORG_SECRET_KEY:-"${USER}:$( pass hosts/storage )"}
     STRIPE_API_VERSION=${STRIPE_API_VERSION:-3.16}
     CONTEXT=${CONTEXT:-VPN}

     ...

     curl https://api.stripe.com/v4.20/balance \
       -u ${ORG_SECRET_KEY} \
       -H "Stripe Version: ${STRIPE_API_VERSION}" \
       -H "Stripe-Context: ${CONTEXT}"

     ...
