Adding new entries into the vault:

    You have three common patterns.

 1. Interactive insert

     user@host:~$ pass insert github/token

    This will prompt you for a password twice.

 2. Generate a strong password

     user@host:~$ pass generate personal/steam 32

    That creates ~/.password-store/personal/steam.gpg with a 32-char random
    password.

 3. Insert raw text from stdin
    Script-friendly:

     user@host:~$ echo "mysecret" | pass insert --multiline ops/myapp/config

    Multiline is important for API keys. PEM blocks, JSON, etc.
