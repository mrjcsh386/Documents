The 'pass' utility: A Unix Philosophy Password Manager:

   'pass' is a command-line tool designed to do one thing well. And, that is to
 manage passwords by encrypting them with GnuPG (GPG).

   It's file-based approach allows you to edit entries with standard text
 editor, letting you add as many notes as you need. For simplicity, we focus
 on its primary function of securing passwords.


The Mechanics of Simplicity:

   The process is straightforward. A file is encrypted with GPG, given a .gpg
 extension, and stored in a folder structure. The plaintext is only ever in
 memory or an active editor buffer... That's it. There is no complex logic,
 database, or background daemon. This simplicity is why it's so reliable.


Extensibility via Plugins:

   Because it's modular, there's a small ecosystem.
 - 'pass-otp': Time-based one-time passwords
 - 'pass-import': Import from common managers
 - 'pass-audit': Look for weak passwords
 - 'pass-update': auto-rotate secrets
 - 'pass-tomb': encrypted container integration


A Flexible Mental Model:

   Picture your password store as a folder tree where every file is secured
 by GPG. You can manage this store using standard UNIX tools like 'git', 'grep',
 and 'mv'.

   The real power becomes clear when you stop thinking of it as a "password
 manager" and start thinking of it as an encrypted key-value store for anything
 textual: API tokens, code snippits, config files, and more.
